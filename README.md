# Yulu Bike Rental Analysis

This repository contains a Jupyter Notebook (`yulu business case.ipynb`) analyzing bike rental demand for Yulu. The analysis includes statistical tests (Kruskal-Wallis, ANOVA), visualizations (boxplots), and recommendations based on day type, seasons, and weather conditions.

## How to Use
- Open `yulu business case.ipynb` to view the analysis.
- Run the notebook in Jupyter to reproduce the results.
